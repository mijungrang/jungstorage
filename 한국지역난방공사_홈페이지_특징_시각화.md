## 4. 투명한 요금 체계 공개 (차별화 요소)

### 4-1. 요금 산정 방식 상세 공개

```
┌──────────────────────────────────────────────────────────────┐
│                   열요금 = 기본요금 + 사용요금                  │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│  🔹 기본요금                                                  │
│    = 계약면적(㎡) × 기본요금 단가                             │
│    또는                                                       │
│    = 계약용량(Gcal/h) × 기본요금 단가                         │
│                                                               │
│  🔹 사용요금                                                  │
│    = 열사용량(Gcal) × 사용요금 단가                           │
│                                                               │
│  🔹 연료비 연동제 ⭐                                          │
│    └─ 국제유가 변동 → 자동 반영                              │
│    └─ 환율 변동 → 자동 반영                                  │
│    └─ 투명한 계산 공식 공개                                  │
│                                                               │
│  🔹 고정비 2년 주기 조정제                                    │
│    └─ 산정 방식 명확히 공개                                  │
│                                                               │
│  🔹 연료비 정산제                                             │
│    └─ 차액 발생 시 정산 프로세스                             │
│                                                               │
└──────────────────────────────────────────────────────────────┘

💡 시사점: 인천종합에너지도 이 수준의 투명성 필요
```
